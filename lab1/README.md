# ЛР1. Реалізація та перевірка зворотного поширення похибки

Мережа $X \to \mathrm{Linear}(4,8) \to \mathrm{ReLU} \to \mathrm{Linear}(8,3)$ на Iris. Прямий і зворотний проходи та крос-ентропія реалізовані вручну в NumPy (float64); PyTorch використано лише в окремій еталонній реалізації для звірки. Градієнти перевірено двома способами: порівнянням з PyTorch autograd і центральною різницею.

## 1. Відтворення

Завершення без помилок означає, що всі твердження прогнозу (для `--buggy`) або всі перевірки (за замовчуванням) виконались: інакше спрацьовує `assert`.

## 2. Дані та фіксовані налаштування

- `sklearn.datasets.load_iris()`: 150 об'єктів, 4 ознаки, 3 класи.
- Стратифікований поділ 70/30: `rng = np.random.default_rng(0)`; класи перебираємо в порядку 0, 1, 2, індекси кожного класу перемішуємо `rng.shuffle`, перші 35 йдуть у навчальну вибірку, решта 15 — у тестову. Разом $N = 105$ навчальних і 45 тестових об'єктів (перевіряється `assert`).
- Стандартизація кожної ознаки: віднімаємо середнє й ділимо на стандартне відхилення ($\mathrm{ddof}=0$), обидві статистики лише з навчальної вибірки; ті самі статистики застосовано до тестової.
- Ініціалізація: новий `default_rng(0)`, спочатку $W_1$, потім $W_2$:

| Параметр | Розмірність | Ініціалізація |
| :-- | :-- | :-- |
| $W_1$ | $4 \times 8$ | He: $\mathcal{N}(0, \sigma^2)$, $\sigma=\sqrt{2/4}$ |
| $b_1$ | $8$ | нулі |
| $W_2$ | $8 \times 3$ | Xavier: $\mathcal{N}(0, \sigma^2)$, $\sigma=\sqrt{2/(8+3)}$ |
| $b_2$ | $3$ | нулі |

He стоїть перед ReLU, Xavier — перед логітами (без активації), як у лекції 3. Усі основні перевірки виконуються **до навчання**, на початкових параметрах і всій навчальній вибірці ($N=105$).

**Позначення.** Як у лекціях, приклади розташовані в рядках: $A^{(0)} = X \in \mathbb{R}^{N\times 4}$. Але, відповідно до умови ЛР1, ваги в NumPy мають форму $(n_{in}, n_{out})$ (у лекціях і `torch.nn.Linear` — $(n_{out}, n_{in})$). Тому при перенесенні параметрів у PyTorch матриці ваг транспонуються (`W.T`), а градієнти PyTorch транспонуються назад.

## 3. Прямий прохід і втрата

Для $\ell = 1, 2$ (приклади в рядках, $b$ додається до кожного рядка):

$$Z^{(1)} = X W_1 + b_1, \qquad A^{(1)} = \mathrm{ReLU}(Z^{(1)}) = \max(0, Z^{(1)}), \qquad Z^{(2)} = A^{(1)} W_2 + b_2 .$$

$Z^{(2)}$ — логіти трьох класів (останній шар без активації). Ймовірності $P = \mathrm{softmax}(Z^{(2)})$ за рядками, $Y$ — матриця унітарних міток, $c_i$ — правильний клас $i$-го об'єкта.

**Чисельно стабільна крос-ентропія** (log-softmax зі зсувом на максимум, лекція 1). Для кожного рядка $z = Z^{(2)}_{i,:}$, $m = \max_k z_k$:

$$\mathrm{LSE}(z) = m + \log\sum_k e^{z_k - m}, \qquad \log p_k = z_k - \mathrm{LSE}(z), \qquad L = -\frac{1}{N}\sum_{i=1}^{N} \log p_{i,c_i} .$$

Зсув на $m$ гарантує, що показники експонент $\le 0$, тому переповнення немає; сума під логарифмом $\ge 1$, тому логарифм визначений. Втрата усереднена за об'єктами. Ймовірності обчислюємо як $\exp(\log p)$.

**Що зберігається для зворотного проходу** (`cache`):

| Збережене | Розмірність | Навіщо потрібне |
| :-- | :-- | :-- |
| $X = A^{(0)}$ | $N\times 4$ | вхід шару 1: $\nabla_{W_1}L = X^\top\Delta^{(1)}$ |
| $Z^{(1)}$ | $N\times 8$ | маска ReLU $\mathbf{1}[Z^{(1)}>0]$ (похідна активації) |
| $A^{(1)}$ | $N\times 8$ | вхід шару 2: $\nabla_{W_2}L = (A^{(1)})^\top\Delta^{(2)}$ |
| $Z^{(2)}$ | $N\times 3$ | логіти; з них отримано $P$ |
| $P$ | $N\times 3$ | база зворотного проходу $\Delta^{(2)} = (P-Y)/N$ |

Окрім того, для переносу сигналу назад потрібна матриця $W_2$.

## 4. Зворотний прохід

Сигнал похибки шару — градієнт втрати за передактивацією, $\Delta^{(\ell)} = \partial L / \partial Z^{(\ell)}$ (для одного прикладу $\delta^{(\ell)} = \nabla_{z^{(\ell)}} L$). Виведення за лекцією 3.

**Крок 1: база (softmax + крос-ентропія).** Для одного прикладу $L = -z_c + \mathrm{LSE}(z)$, звідки $\partial L/\partial z_k = -y_k + e^{z_k}/\sum_j e^{z_j} = p_k - y_k$, тобто $\delta^{(2)} = p - y$. Втрата усереднена за пакетом, тому внесок кожного прикладу має множник $1/N$, який враховуємо **один раз**, на виході:

$$\Delta^{(2)} = \frac{P - Y}{N}, \qquad \Delta^{(2)} \in \mathbb{R}^{N\times 3}.$$

**Крок 3 для шару 2: градієнти за параметрами.** Вага $W_2[j,i]$ множить $a^{(1)}_j$ і веде до нейрона $i$, тому $\partial L/\partial W_2[j,i] = \sum_n A^{(1)}_{n,j}\Delta^{(2)}_{n,i}$. Зсув додається без множника, тому його градієнт — сума сигналів за прикладами:

$$\nabla_{W_2} L = (A^{(1)})^\top \Delta^{(2)} \in \mathbb{R}^{8\times 3}, \qquad \nabla_{b_2} L = \sum_{i=1}^{N} \Delta^{(2)}_{i,:} \in \mathbb{R}^{3}.$$

**Крок 2: рекурентність.** Градієнт за виходом прихованого шару та перенесення через ReLU (поелементне множення на маску замість матриці $D^{(1)}$):

$$\frac{\partial L}{\partial A^{(1)}} = \Delta^{(2)} W_2^\top \in \mathbb{R}^{N\times 8}, \qquad \Delta^{(1)} = \Big(\Delta^{(2)} W_2^\top\Big) \odot \mathbf{1}[Z^{(1)} > 0] \in \mathbb{R}^{N\times 8}.$$

Транспонування $W_2^\top$ виникає, бо активація $a_j$ впливає на втрату через стовпець $j$ матриці ваг. Для $z = 0$ беремо похідну ReLU, рівну нулю (домовленість PyTorch).

**Крок 3 для шару 1:**

$$\nabla_{W_1} L = X^\top \Delta^{(1)} \in \mathbb{R}^{4\times 8}, \qquad \nabla_{b_1} L = \sum_{i=1}^{N} \Delta^{(1)}_{i,:} \in \mathbb{R}^{8}.$$

Множник $1/N$ не з'являється вдруге: він уже міститься в $\Delta^{(2)}$ і переноситься рекурентністю. Градієнт за зсувом — **сума** за рядками, а не середнє.

**Розмірності** (фактичні, друкуються `main.py`):

**Розмірності масивів (N = 105)**

| Масив | Зміст | Фактична форма | Очікувана |
| :-- | :-- | --: | --: |
| X | A⁽⁰⁾ | (105, 4) | N × 4 |
| y | мітки класів c_i | (105,) | N |
| W1 / b1 | параметри шару 1 | (4, 8) / (8,) | 4 × 8 / 8 |
| Z1 | Z⁽¹⁾ = XW1 + b1 | (105, 8) | N × 8 |
| A1 | A⁽¹⁾ = ReLU(Z⁽¹⁾) | (105, 8) | N × 8 |
| W2 / b2 | параметри шару 2 | (8, 3) / (3,) | 8 × 3 / 3 |
| Z2 | Z⁽²⁾ = A⁽¹⁾W2 + b2 (логіти) | (105, 3) | N × 3 |
| P | softmax(Z⁽²⁾) | (105, 3) | N × 3 |
| ∇W1 | Xᵀ Δ⁽¹⁾ | (4, 8) | 4 × 8 |
| ∇b1 | Σ рядків Δ⁽¹⁾ | (8,) | 8 |
| ∇W2 | (A⁽¹⁾)ᵀ Δ⁽²⁾ | (8, 3) | 8 × 3 |
| ∇b2 | Σ рядків Δ⁽²⁾ | (3,) | 3 |

Усі розмірності збігаються з очікуваними.

## 5. Звірка з PyTorch

Еталон (`model_torch.py`): `nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 3)).double()`; у нього скопійовано параметри NumPy-мережі (`weight.copy_(W.T)`, `bias.copy_(b)`), втрата — `F.cross_entropy(..., reduction="mean")`, градієнти отримано `loss.backward()` і транспоновано назад. Порівнюються втрата та **всі елементи** чотирьох градієнтів на тих самих даних; перед порівнянням перевіряється скінченність усіх значень.

## 6. Чисельна перевірка градієнтів

Для $\theta_i \in \{W_1[0,0],\ b_1[0],\ W_2[0,0],\ b_2[0]\}$ на початкових вагах і всій навчальній вибірці: зберігаємо $\theta_i$; збільшуємо **лише** його на $\varepsilon = 10^{-6}$ і отримуємо $L_+$; встановлюємо $\theta_i - \varepsilon$ і отримуємо $L_-$; відновлюємо початкове значення та обчислюємо

$$g_{\mathrm{num},i} = \frac{L_+ - L_-}{2\varepsilon}.$$

Критерій: $|g_{\mathrm{num}} - g_{\mathrm{manual}}| \le 10^{-7}$. Згідно з лекцією 3, додатково перевіряється, що збурення $\pm\varepsilon$ не змінює жодного знака в $Z^{(1)}$: маски $\mathbf{1}[Z^{(1)}>0]$ при $\theta-\varepsilon$, $\theta$ і $\theta+\varepsilon$ збігаються (інакше різниця змішала б дві гілки ReLU) — перевірка виконується `assert`-ом у `checks.py`. Усі чотири градієнти ненульові, тож перевірка змістовна.

**Чисельна перевірка градієнтів**

| Параметр | Градієнт backward() | Чисельна похідна | Абсолютна різниця | Перевірку пройдено |
| :-- | --: | --: | --: | --: |
| W1[0, 0] | -1.992018433e-02 | -1.992018439e-02 | 6.034e-11 | ✓ так |
| b1[0] | -7.056611158e-02 | -7.056611162e-02 | 3.633e-11 | ✓ так |

| b2[0] | 8.552164484e-02 | 8.552164499e-02 | 1.460e-10 | ✓ так |

_ε = 1e-06, критерій: |g_num − g_manual| ≤ 1e-07_

Усі чотири перевірки пройдено. Різниці порядку $10^{-10}$ — це власна похибка центральної різниці (зрізання $\sim h^2$ та заокруглення $\sim u|L|/h$, лекція 3), а не помилка в `backward()`; вони на три порядки менші за допуск $10^{-7}$.

## 7. Дослід із навмисною помилкою

З градієнта за логітами тимчасово прибрано ділення на $N$: $\Delta^{(2)} = P - Y$ замість $(P-Y)/N$ (параметр `omit_batch_mean=True` у `backward`); функція втрати не змінена. Параметри ті самі, $N=105$ ті самі, оновлень ваг між порівняннями немає. Еталон PyTorch і формула чисельної похідної не змінювались. За замовчуванням `backward` працює правильно; дослід відтворюється командою `uv run main.py --buggy`.

### Прогноз (записано до запуску)

1. Втрата. L залежить лише від прямого проходу й крос-ентропії, а прибирання ділення стосується тільки backward(). На тих самих параметрах L не зміниться: |L_NumPy − L_PyTorch| лишиться ≤ 1e-12.

2. Ненульові градієнти. Δ⁽²⁾ = P − Y замість (P − Y)/N, а backprop лінійний за Δ⁽²⁾, тому всі чотири градієнти зростуть рівно в N = 105 разів (нулі лишаться нулями, напрямок градієнта збережеться): g_bug = N · g.

3. Які перевірки виявлять помилку. Звірка з PyTorch: градієнти W1, b1, W2, b2 не пройдуть (різниці ≫ 1e-12), а втрата пройде. Чисельна перевірка: для всіх чотирьох параметрів g_manual ≈ N · g_num, |g_num − g_manual| ≈ (N − 1)|g_num| ≫ 1e-7. Перевірка втрати помилку не виявить.

### Пояснення

- **Втрата не змінилась**: $L$ обчислюється прямим проходом і крос-ентропією, які в досліді не чіпали, тому звірка *втрати* помилку не бачить. Помилка видна лише в градієнтах.
- **Градієнти зросли рівно в $N$ разів**: усі градієнти лінійні за $\Delta^{(2)}$ (формули розділу 4 містять $\Delta^{(2)}$ в першій степені), тому множник $1/N$, пропущений на виході, переноситься рекурентністю в усі чотири градієнти. Це підтверджує таблиця масштабу: $g_{\mathrm{bug}}/g = 105$ для всіх ненульових елементів.
- **Обидві перевірки виявили помилку**: звірка з PyTorch (різниці $\sim 10^1 \gg 10^{-12}$) та чисельна перевірка (напр. для $W_1[0,0]$: $-2.0916$ проти $-0.01992$; різниця $= (N-1)|g_{\mathrm{num}}| \approx 2.07 \gg 10^{-7}$). Чисельна перевірка не залежить від PyTorch і виявляє помилку, бо опирається лише на функцію втрати. Реалізація, яка узгоджується з *функцією втрати*, — це реалізація з множником $1/N$.
- Результат досліду відповідає прогнозу за всіма трьома пунктами; правильний результат досліду — **виявлена помилка**.

## 8. Висновки

1. Прямий прохід, стабільна крос-ентропія (log-softmax зі зсувом на максимум) і ручний зворотний прохід реалізовано в NumPy у float64; усі розмірності відповідають постановці.
2. Втрата та всі елементи чотирьох градієнтів збігаються з PyTorch з точністю $\le 2.3\cdot 10^{-16}$ при допуску $10^{-12}$.
3. Центральна різниця з $\varepsilon=10^{-6}$ підтвердила $W_1[0,0]$, $b_1[0]$, $W_2[0,0]$, $b_2[0]$ з похибкою $\le 1.5\cdot 10^{-10}$ при допуску $10^{-7}$ без перетину зламу ReLU.
4. Пропущений множник $1/N$ не змінює втрату, але збільшує всі градієнти в $N=105$ разів; обидві перевірки це виявляють.
5. Градієнти перевіряються до навчання; мінімальна точність класифікації умовою не встановлюється, тому навчання в роботі не виконується.
